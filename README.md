# Selector de Servicios Mineros — INVERSIONESJJZURCO

Aplicación web interactiva para orientar a clientes y responsables de operación hacia los servicios mineros más adecuados según su necesidad, ubicación y prioridades.

## Uso

Abra `outputs/index.html` en un navegador moderno. No requiere instalación ni servidor local.

## Incluye

- Evaluación guiada de cuatro pasos y recomendaciones personalizadas.
- Catálogo de servicios con filtros por categoría y buscador.
- Fichas de detalle y formulario de cotización demostrativo.
- Diseño responsive para escritorio, tablet y celular.

## Estructura

- `outputs/index.html`: interfaz principal.
- `outputs/styles.css`: estilos visuales responsive.
- `outputs/app.js`: servicios, lógica de recomendaciones e interacciones.
